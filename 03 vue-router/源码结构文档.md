# Vue Router 源码结构文档

## 项目概述

**项目名称**: vue-router
**版本**: 5.0.4
**架构类型**: 模块化多文件架构 (Modular Multi-File)
**许可证**: MIT
**主仓库**: https://github.com/vuejs/router

Vue Router 是 Vue 3 官方路由管理器，支持声明式路由配置、嵌套路由、导航守卫、路由懒加载等高级功能。

## 核心模块详解

### 1. index.ts (入口模块)

**路径**: `packages/router/src/index.ts` (~253行)

**职责**: 统一导出所有公共 API

**导出内容**:

| 类别 | 导出 |
|------|------|
| **历史记录** | `createWebHistory`, `createWebHashHistory`, `createMemoryHistory` |
| **路由** | `createRouter`, `Router`, `RouterOptions` |
| **匹配器** | `createRouterMatcher`, `RouterMatcher` |
| **查询** | `parseQuery`, `stringifyQuery` |
| **类型** | `RouteRecord`, `LocationQuery`, `RouteLocationNormalized` |
| **守卫** | `onBeforeRouteLeave`, `onBeforeRouteUpdate`, `loadRouteLocation` |
| **组件** | `RouterLink`, `RouterView`, `useLink` |
| **错误** | `NavigationFailureType`, `isNavigationFailure` |
| **自动路由** | `unplugin/vite`, `unplugin/webpack` 等 |
| **实验性** | `experimental` 相关 API |

### 2. router.ts (Router 类)

**路径**: `packages/router/src/router.ts` (~1088行)

**职责**: 路由实例管理，导航控制

**主要接口**:

```typescript
export interface RouterOptions extends EXPERIMENTAL_RouterOptions_Base {
  routes: Readonly<RouteRecordRaw[]>
  history: RouterHistory
  scrollBehavior?: RouterScrollBehavior
}

export interface Router extends EXPERIMENTAL_Router_Base {
  readonly options: RouterOptions
  currentRoute: Ref<RouteLocationNormalized>

  addRoute(parentName: string, route: RouteRecordRaw): () => void
  removeRoute(name: string): void
  getRoutes(): RouteRecordMatcher[]

  push(to: RouteLocationRaw): Promise<NavigationFailure | undefined>
  replace(to: RouteLocationRaw): Promise<NavigationFailure | undefined>
  back(): void
  forward(): void

  beforeEach(guard: NavigationGuard): () => void
  afterEach(guard: NavigationHookAfter): () => void
  onError(guard: ErrorListener): () => void

  isReady(): Promise<void>
}
```

### 4. history/ (历史记录管理)

#### 4.1 common.ts - RouterHistory 接口

**路径**: `packages/router/src/history/common.ts` (~185行)

**职责**: 定义历史记录接口

```typescript

  readonly base: string
  readonly location: HistoryLocation
  readonly state: HistoryState

  push(to: HistoryLocation, data?: HistoryState): void
  replace(to: HistoryLocation, data?: HistoryState): void
  go(delta: number): void
  back(): void
```

#### 4.3 hash.ts - Hash History

**路径**: `packages/router/src/history/hash.ts`

#### 4.4 memory.ts - Memory History

**路径**: `packages/router/src/history/memory.ts`

**实现**: `createMemoryHistory` - 不依赖 URL，适用于 SSR

## 技术特点

### 1. 适配器模式 (History)

```typescript
// 不同环境使用不同的 History 实现
const history = isBrowser
  ? createWebHistory()   // HTML5 History
  : createMemoryHistory() // Memory (SSR)
```

### 2. 路由匹配算法

```typescript
// 路径排名决定路由优先级
const score = comparePathParserScore(a, b)
// 高分优先，相同分数按定义顺序
```

### 3. 守卫链式调用


## 总结

Vue Router 5.0 采用**模块化分层架构**：

1. **入口层**: 统一的 ES Module / CommonJS 导出
2. **路由层**: Router 类 + 导航控制
3. **匹配层**: RouterMatcher + 路径解析 + 排名
4. **历史层**: RouterHistory + HTML5/Hash/Memory 三种实现
5. **组件层**: RouterLink + RouterView
6. **守卫层**: NavigationGuards + 异步组件解析
7. **自动路由**: unplugin + 代码生成

这种架构的优势：

- **环境适应**: 同一套 API 支持浏览器、Node.js、SSR
- **类型安全**: 完整的 TypeScript 类型支持
- **可扩展性**: 插件系统支持自动路由、IDE 集成
- **性能优化**: 路由排名算法确保正确匹配
- **开发体验**: DevTools 集成、热更新支持
